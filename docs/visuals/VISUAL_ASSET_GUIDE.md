# UsahaNaik Visual Asset Guide

This guide explains the final visual assets prepared for portfolio and LinkedIn presentation.

## Asset Locations

- Runtime screenshot workflow: `docs/evidence/screenshots/final/`
- Portfolio mockups: `docs/visuals/mockups/`
- LinkedIn campaign visuals: `docs/visuals/linkedin_campaign/`
- Visual package ZIP: `dist/UsahaNaik_LinkedIn_Visual_Package.zip`

## Screenshot Status

No runtime Android screenshots were captured during this packaging task because no emulator or physical device was attached when `adb devices` was checked.

The screenshot folder includes `SCREENSHOT_CAPTURE_GUIDE.md` so real runtime screenshots can be captured later from a Medium Phone emulator or Android device. Any image in the mockup or LinkedIn folders should be treated as a designed presentation asset, not a runtime screenshot.

## Mockups

Use these files for portfolio pages, README previews, and project thumbnails:

- `mockup_desktop.png` - wide dashboard-style product overview.
- `mockup_mobile.png` - smartphone presentation for the Android app experience.
- `mockup_showcase.png` - combined showcase visual with feature and tech stack highlights.

The mockups are deterministic source-based visuals generated by `scripts/generate_visual_assets.py`. They reflect the implemented UsahaNaik product scope: local-first dashboard, business setup, finance tracking, weekly plan, content planner, report, reminders, demo mode, and bilingual support.

## LinkedIn Assets

Use these campaign visuals for a LinkedIn post or carousel:

- `linkedin_cover.png` - best for a wide LinkedIn image post.
- `linkedin_square_post.png` - best for a single square highlight post.
- `linkedin_carousel_01_intro.png` - opening slide.
- `linkedin_carousel_02_features.png` - feature summary slide.
- `linkedin_carousel_03_tech_stack.png` - technology stack slide.
- `linkedin_carousel_04_demo.png` - workflow/demo slide.
- `linkedin_carousel_05_closing.png` - closing CTA slide.
- `linkedin_banner.png` - wide portfolio or profile banner.

The campaign language is Bahasa Indonesia by default and keeps claims honest: UsahaNaik is local-first, auth-ready, AI-ready, and deterministic/local in this version.

## Regenerate Visuals

Generate all mockups and campaign visuals:

```bash
python3 scripts/generate_visual_assets.py --target all
```

Build and verify the visual package ZIP:

```bash
python3 scripts/build_visual_package.py
python3 scripts/verify_visual_package.py
```

## Known Limitations

- Runtime screenshots are not included unless captured from a real emulator/device.
- The visual package is for presentation assets only, not source-code backup.
- No generated visual claims real backend authentication, cloud sync, paid AI API usage, guaranteed profit increase, or professional financial advice.
