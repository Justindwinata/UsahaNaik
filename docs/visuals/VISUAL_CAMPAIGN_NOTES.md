# UsahaNaik LinkedIn Campaign Notes

## Campaign Positioning

UsahaNaik is presented as a local-first Android business growth planner for Indonesian UMKM owners. The campaign should focus on portfolio engineering quality, product thinking, offline-first architecture, and practical business workflows.

## Suggested LinkedIn Caption

Saya membangun UsahaNaik, sebuah aplikasi Android local-first untuk membantu UMKM mengatur profil bisnis, mencatat keuangan sederhana, melihat dashboard kesehatan bisnis, menjalankan weekly plan, membuat ide konten, mengatur kalender konten, meninjau retrospective, dan membuat ringkasan report.

Fokus teknis:

- Kotlin + Jetpack Compose
- Room local persistence
- Material Design 3
- Rule-based diagnosis engine
- Weekly growth plan generator
- Content planner lokal/deterministik
- Reminder architecture
- Bahasa Indonesia + English
- Demo mode untuk portfolio walkthrough

Catatan penting: versi ini belum menggunakan backend, cloud sync, real AI API, atau autentikasi sungguhan. Semua data utama disimpan lokal di perangkat, dan insight bisnis adalah panduan perencanaan, bukan jaminan hasil bisnis.

## Safe Claims

Use:

- Local-first Android app
- Rule-based business insights
- Estimated financial summary
- Content planning suggestions
- Auth-ready placeholder flow
- AI-ready provider architecture
- Demo mode for portfolio review

Avoid:

- Guaranteed profit increase
- Guaranteed sales growth
- Professional financial advice
- Official accounting or tax report
- Real cloud sync
- Real backend authentication
- Real paid AI generation
