# Final Portfolio Checklist

## Product Readiness

- [ ] App launches successfully.
- [ ] Indonesian is the default language.
- [ ] English language switch is available.
- [ ] Auth-ready Login/Register screens are clearly placeholders.
- [ ] Local mode works without account creation.
- [ ] Demo data can populate the main workflows.
- [ ] Demo data can be cleared.

## Main Workflows

- [ ] Business setup creates a local profile.
- [ ] Dashboard displays local business, finance, plan, content, report, and reminder state.
- [ ] Financial entries validate and save locally.
- [ ] Weekly plan can be generated and task progress updates.
- [ ] Retrospective can be generated and saved.
- [ ] Content ideas can be generated, saved, filtered, and scheduled.
- [ ] Business Report renders local KPI summaries and export-ready text.
- [ ] Reminders can be created, listed, paused, enabled, and deleted.

## Visual Quality

- [ ] Top content is not clipped on Medium Phone.
- [ ] Bottom navigation does not cover scroll content.
- [ ] Cards are readable and not excessively tall.
- [ ] Empty/loading/error states are clear.
- [ ] Primary CTA hierarchy is obvious.
- [ ] Copy remains honest about local-first behavior.

## Evidence

- [ ] Unit tests pass.
- [ ] Debug APK builds.
- [ ] `git diff --check` passes.
- [ ] Manual emulator QA checklist is available.
- [ ] Screenshots are captured only if an emulator/device is actually available.

## Portfolio Notes

- [ ] README explains product, architecture, demo mode, limitations, and setup.
- [ ] Changelog includes finalization sprint.
- [ ] Portfolio presentation notes explain what is implemented and what is intentionally deferred.
